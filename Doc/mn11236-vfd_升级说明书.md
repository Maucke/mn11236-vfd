# VFD 多功能显示系统

## 固件升级说明书

感谢您使用本产品。
本设备支持 **USB 固件升级功能**，无需安装任何软件，只需通过电脑复制升级文件即可完成更新。

---

# 一、升级准备

升级前请准备以下内容：

* 一台电脑（Windows / macOS 均可）
* USB 数据线
* 最新固件升级文件（由厂家提供）

注意：

* 升级文件为 **`.bin` **
* 升级过程中 **请勿断开 USB**

---

# 二、进入升级模式

请按照以下步骤操作：

### 1. 断开设备电源

确保设备当前 **完全断电**。

---

### 2. 按住任意一个按键

设备有两个按键：

* 上键
* 下键

**按住任意一个按键即可。**

---

### 3. 连接 USB 到电脑

在 **保持按键按住的情况下**：

1. 使用 USB 数据线连接设备与电脑
2. 等待约 2 秒
3. 电脑会自动识别出一个 **U 盘设备**

---

# 三、升级步骤

当电脑识别出 U 盘后：

### 1. 打开该 U 盘

电脑中会出现一个新的可移动磁盘。

---

### 2. 拖入升级文件

将升级文件：

```
xxxx.bin
```

**直接拖入该 U 盘。**

---

### 3. 等待升级完成

复制完成后：

* 设备会 **自动写入固件**
* U 盘可能会 **自动断开**
* 设备随后会 **自动重启**

升级即完成。

---

# 四、升级完成确认

升级完成后：

1. 设备会自动启动
2. 进入正常显示界面

您可以在：

```
菜单 → About（关于）
```

查看：

* 系统版本
* 编译日期

以确认升级成功。

---

# 五、升级失败处理

如果升级未成功，可以按以下方式处理：

### 方法一：重新升级

1. 断开 USB
2. 重新按住任意按键
3. 重新连接 USB
4. 再次复制升级文件

---

### 方法二：更换 USB 数据线

部分 USB 线仅支持充电，不支持数据传输。

建议使用 **标准数据线**。

---

# 六、注意事项

* 升级过程中 **不要拔掉 USB**
* 升级文件 **不要改名**
* 每次升级 **只复制一个文件**
* 升级失败可重复操作，不会损坏设备

---

# 七、技术说明

升级模式基于 **USB Mass Storage Device（U盘模式）** 实现：

* 无需安装驱动
* 电脑自动识别
* 拖拽文件即可升级

---

# 八、升级文件获取

最新固件可通过以下方式获取：

* 官方发布页面
* 产品支持页面
* 技术支持提供
